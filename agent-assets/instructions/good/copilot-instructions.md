# Repository instructions

This repository measures how prompt, model, and harness choices affect AI cost.

- Keep measured results separate from estimates; never present a hypothesis as a benchmark.
- Compare runs only when task, fixture, and acceptance criteria match.
- Report failed-run spend and cost per accepted completion.
- Cite a source and date for any price or product behavior.

Area-specific rules live in `.github/instructions/` and load only for matching files.
