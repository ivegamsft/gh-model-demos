# Policy retrieval corpus

These are fictional product policies. Filter by region, product, and purchase
date before selecting a version. The archive was edited more recently than
the applicable policy, deliberately testing edit-date versus effective-date
selection. Unsupported exceptions must remain unsupported.

There is no npm application. From the repository root run
`node --test tests/fixtures.test.mjs` for the content audit.
The prompt's required abstention is:
"The retrieved evidence does not establish the policy."
